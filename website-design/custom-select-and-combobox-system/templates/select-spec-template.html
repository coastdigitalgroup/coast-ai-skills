Design Rules & Blueprint Notes

  • Focus Loop: Focus remains trapped inside dropdown if list is active. Pressing Escape collapses panel and returns focus instantly to combo-trigger-id.
  • Interactive Target minimums: custom-select-trigger is 44px in height. Individual options have a minimum height of 40px, with generous vertical spacing.
  • Z-Index Isolation: Dropdown panel should be assigned z-index: 1000 or sit on Elevation Level 3/4 to float cleanly above absolute inputs or card borders.
  • Scroll Containment: The list box has overscroll-behavior: contain to prevent mouse scrolls from sliding the underlying body text once boundary is hit.
