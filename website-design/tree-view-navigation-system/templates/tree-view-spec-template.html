Interactive Design Specification Specs

This layout represents a Tree View System spec template. It is designed to be easily parsed by developer engineers to write high-fidelity CSS and accessible JavaScript controllers.

  • role="tree" — Applied on the outermost container list holding the directory.
  • role="treeitem" — Applied on each active row item in the list, providing the keyboard target.
  • role="group" — Applied on child containers, letting screen readers identify nesting bounds.
  • aria-expanded — Applied strictly on folder/parent elements to sync disclosure triangles.
  • style="--tree-depth" — Numeric variable representing tree nesting depth, keeping CSS clean.
