❌ Naive Approach (Style Leak & Reflow Jank)
// 1. Direct CSS top/left animation (Triggers Layout Reflow) // 2. Persistent fill: 'forwards' without cleanup element.animate([ { top: '0px', left: '0px' }, { top: `${dy}px`, left: `${dx}px` } ], { duration: 400, fill: 'forwards' // ⚠️ LEAKS WAAPI STYLES IN MEMORY FOREVER! });
✅ WAAPI FLIP Protocol (Compositor & Cleaned)
// 1. Capture FLIP Delta (First vs Last) // 2. Animate Compositor Transform const animation = element.animate([ { transform: `translate(${dx}px, ${dy}px)` }, { transform: 'translate(0, 0)' } ], { duration: 400, easing: 'cubic-bezier(0.2, 0, 0, 1)' }); // 3. Clean up style stack upon completion await animation.finished; animation.commitStyles(); animation.cancel(); // Prevents memory leak!
