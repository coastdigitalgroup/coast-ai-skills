1. Synchronous vs Asynchronous Scroll Tracking

Traditional scroll tracking attaches event listeners directly to the window scroll object and fires getBoundingClientRect() continuously on the main thread. This forces synchronous style recalcs and layout thrashing.

IntersectionObserver offloads bounding calculations to the browser's compositor layer. Notifications are batched off the main thread and delivered asynchronously.
