1. Common Anti-Pattern vs. Singleton Pooling

Anti-Pattern (Before): Creating a separate new IntersectionObserver() for every element on page scroll leads to excessive memory consumption and main-thread layout thrashing.

Optimized Pattern (After): The IntersectionObserverManager pools identical root, rootMargin, and threshold options into a single shared observer instance.
