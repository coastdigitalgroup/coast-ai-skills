Custom Web Components: Tab Panel & Modal Dialog

Demonstrating Custom Elements v1, Shadow DOM v1 style isolation, slot projection, attribute reflection, and composed custom events.

1. Tab Group Component (<ui-tab-group>)

Notice that global button styles (red background above) do NOT bleed into the component's internal shadow DOM buttons!

Overview

System Overview

This tab panel is powered by standards-based Web Components. It uses Shadow DOM for style encapsulation and slot projection for host markup.

 Encapsulation

Shadow DOM Isolation

Styles defined inside the component remain encapsulated. CSS variables (`var(--...)`) allow host pages to customize design tokens without selector leakage.

 Accessibility

ARIA Keyboard Navigation

Use Left/Right arrow keys to switch active tabs. Focus is managed automatically according to WAI-ARIA Tabs design pattern specifications.

2. Modal Dialog Component (<ui-modal>)

This modal dialog is rendered entirely inside an open Shadow Root.

Key Features demonstrated:

  • Native connectedCallback & disconnectedCallback memory teardown.
  • Reactive open attribute reflection.
  • Focus trapping and Escape key closure listeners.
  • Composed modal-close CustomEvent dispatching.
