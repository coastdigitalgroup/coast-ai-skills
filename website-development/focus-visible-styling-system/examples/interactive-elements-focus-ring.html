Test keyboard navigation using Tab and Shift + Tab. Compare the behavior between mouse clicks and keyboard focus.

1. Action Buttons

FAIL Inaccessible Button

Uses outline: none on focus. Mouse and keyboard users see zero visual focus feedback.

PASS WCAG 2.2 Compliant Button

Uses :focus-visible with double-ring high-contrast styling and forced-colors fallbacks.

2. Text Form Controls

FAIL Low Contrast Outline

Focus outline fails WCAG 2.2 SC 2.4.11 3:1 contrast ratio against the light/dark background.

PASS Dual-Ring Focused Input

Features 3:1+ high-contrast focus ring with distinct border highlighting.

3. Overflow Clipping Defenses

FAIL Outer Ring Clipped

Positive outline-offset: 4px inside an overflow: hidden card gets clipped off.

PASS Inset Focus Ring

Negative outline-offset: -2px keeps focus outline within container bounds.
