Roving Tabindex Spatial Navigation

Demonstrates accessible keyboard navigation for composite widgets (1D Horizontal Toolbar and 2D Grid) using the Roving Tabindex pattern. Each composite widget acts as a single Tab stop. Use Arrow keys, Home, and End to navigate sub-items.

2. Horizontal Formatting Toolbar (1D Navigation)

Keys: ArrowLeft / ArrowRight (or ArrowUp / ArrowDown), Home, End.

3. Interactive Palette Grid (2D Navigation - 4 Columns)

Keys: ArrowLeft, ArrowRight, ArrowUp, ArrowDown, Home, End.
