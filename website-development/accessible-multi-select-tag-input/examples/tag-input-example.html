How to test keyboard accessibility:
  • Add: Type a term (e.g. "HTML") and press Enter.
  • Navigate to tags: Ensure input is empty, and press Backspace or Left Arrow. Focus moves to the "CSS" chip.
  • Browse: Use Left Arrow and Right Arrow to move focus through chips. Focus stays bound as a single tab stop!
  • Delete: Focus a chip and press Backspace or Delete. Focus moves to the next/prev chip.
  • Exit: Press Escape or arrow right past the last tag to return focus immediately back to the typing input.
