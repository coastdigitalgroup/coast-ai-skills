# Case Study: Optimizing Product Bundling Strategy & UI for a Premium Skincare Brand

## Executive Summary

**Brand Type:** Direct-to-Consumer (DTC) Skincare & Wellness Brand
**Primary Challenge:** High site traffic and healthy baseline conversion rates (2.8%), but stagnant Average Order Value ($58) driven by customers purchasing single cleanser or moisturizer SKUs.
**Optimization Applied:** Applied the **Product Bundle Optimization** framework to design a 3-tier "Routine Kit" bundle structure on PDPs, a streamlined Build Your Own Bundle (BYOB) flow, and explicit dollar-value savings framing.
**Outcome:** Increased Average Order Value from **$58.00 to $74.50 (+28.4%)**, boosted Bundle Take Rate from **8.2% to 27.5%**, and increased Gross Profit Dollars per Order by **+$11.20 (+24.1%)**.

---

## The "Before" State

### Overview & Initial Setup
The brand offered individual skincare products (Cleanser $24, Vitamin C Serum $38, Night Moisturizer $32) and had an existing static "Hydration Trio Set" page listed as a separate product in the catalog.

```text
[ Current PDP Layout - Before ]

Product Title: Gentle Hydrating Cleanser
Price: $24.00
Variant: 150ml

[ Add to Cart Button ]

--- Description & Ingredients ---

(Separate PDP for "Hydration Trio Set" existed deep in the navigation, but was rarely visited)
```

### Identified Friction Points & UX Failures
1. **Hidden Bundle Discovery:** The "Hydration Trio Set" lived on its own isolated product page. Shoppers browsing the main cleanser or moisturizer pages had zero visibility into the bundled set or potential savings.
2. **Mental Math Friction:** The static bundle page listed "Hydration Trio Set - $78.00 (Value $94.00)". It failed to show standalone prices side-by-side or highlight explicit savings ($16 OFF / 17% OFF).
3. **Choice Paralysis in BYOB:** The brand tested a custom bundle page where customers were forced to scroll through 18 items with individual quantity selectors on a single long page. Mobile drop-off on this builder was 68%.
4. **No Default Anchor:** On product pages, single items were selected by default with no visual prompt guiding customers toward multi-item tiers.

### Baseline Key Performance Indicators (30-Day Pre-Optimization)
- **Average Order Value (AOV):** $58.00
- **Site Conversion Rate (CVR):** 2.80%
- **Bundle Take Rate:** 8.2% (Percentage of total orders containing 2+ bundled items)
- **Gross Margin per Order:** $46.40 (80% core product gross margin)
- **Revenue Per Visitor (RPV):** $1.62

---

## The Optimization Strategy (The "After" State)

### 1. PDP "Routine Kit" Bundle Widget Integration
Instead of hiding bundles on separate pages, a high-contrast **"Frequently Bought Together / Routine Builder"** box was integrated directly into every individual product detail page beneath the primary Buy Box.

```text
[ Optimized PDP Buy Box - After ]

Product Title: Gentle Hydrating Cleanser
Price: $24.00

--- BUNDLE & SAVE (20% OFF) ---
[x] Gentle Hydrating Cleanser ....... $24.00
[x] Vitamin C Daily Serum ........... $38.00
[x] Night Renewal Cream ............. $32.00

Total Value: $94.00
Bundle Price: $75.20  (YOU SAVE $18.80!)

[ ADD 3-STEP ROUTINE TO CART ]
```

### 2. Tiered Quantity Anchoring (Buy More, Save More)
For single-product replenishment items, a 3-tier card selector was embedded directly into the primary Buy Box, pre-selecting Tier 2 by default.

```text
Select Supply Tier:
┌────────────────────────────────────────────────────────┐
│ [ ] 1 Bottle — $38.00 ($38/unit)                      │
├────────────────────────────────────────────────────────┤
│ [*] 2 Bottles — $64.60 ($32.30/unit) [SAVE 15%]       │
│     ★ MOST POPULAR ★                                  │
├────────────────────────────────────────────────────────┤
│ [ ] 3 Bottles — $85.50 ($28.50/unit) [SAVE 25%]       │
│     🏆 BEST VALUE                                      │
└────────────────────────────────────────────────────────┘
```

### 3. Step-Reduced BYOB Interface
Replaced the long 18-item scroll page with a 3-step tabbed modal builder:
- **Step 1:** Select Cleanser (6 options)
- **Step 2:** Select Treatment Serum (6 options)
- **Step 3:** Select Moisturizer (6 options)
- **Sticky Footer Progress Bar:** *"Add 1 more item to unlock 20% OFF + Free Shipping!"*

### 4. Clear Value Framing
Replaced vague percentage badges with dual savings callouts: **~~$94.00~~ $75.20 (Save $18.80 / 20% OFF)**.

---

## Results & Impact Comparison

After running a 30-day split test across 120,000 unique site visitors, the optimized bundle architecture delivered significant lifts across all key growth metrics.

| Metric | Before Optimization | After Optimization | Lift / Delta |
| :--- | :--- | :--- | :--- |
| **Average Order Value (AOV)** | $58.00 | $74.50 | **+28.4%** |
| **Bundle Take Rate** | 8.2% | 27.5% | **+235.3%** |
| **Site Conversion Rate (CVR)** | 2.80% | 2.92% | **+4.3%** |
| **Revenue Per Visitor (RPV)** | $1.62 | $2.18 | **+34.6%** |
| **BYOB Flow Completion Rate** | 32.0% | 58.4% | **+82.5%** |
| **Gross Profit Dollars / Order** | $46.40 | $57.60 | **+$11.20 (+24.1%)** |

### Key Takeaways
1. **In-Context Merchandising Wins:** Bringing the bundle offer directly into the PDP Buy Box increased bundle visibility by 400% compared to having a standalone bundle product page.
2. **Explicit Dollar Framing Motivates:** Showing exact dollar savings ("SAVE $18.80") performed 18% better in A/B tests than showing percentage savings alone ("20% OFF").
3. **Defaults Matter:** Pre-selecting Tier 2 (2 Bottles - 15% OFF) shifted 34% of single-bottle buyers into multi-bottle buyers without decreasing primary conversion rate.
