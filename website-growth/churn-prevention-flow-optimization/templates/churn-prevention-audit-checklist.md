# Churn Prevention & Cancellation Flow Audit Checklist

Use this audit checklist and strategy matrix to evaluate your self-serve subscription cancellation flow, identify friction and dark patterns, and implement targeted retention deflection offers.

---

## 1. Flow Accessibility & Compliance Audit

| Audit Criteria | Status | Issues Identified / Action Items |
| :--- | :---: | :--- |
| **Self-Serve Accessibility:** Is the "Cancel Subscription" option accessible in account settings in under 2 clicks without forced phone/chat requirements? | [ ] Pass<br>[ ] Fail | |
| **FTC Click-to-Cancel Compliance:** Is canceling the subscription as easy as signing up, with no deceptive multi-step mazes? | [ ] Pass<br>[ ] Fail | |
| **Equal Button Prominence:** Are deflection buttons and cancellation continuation CTAs clearly distinguishable without deceptive color/size manipulation? | [ ] Pass<br>[ ] Fail | |
| **Paid Access Term Preservation:** Does the user retain full access to their paid features until the end of their current paid billing cycle? | [ ] Pass<br>[ ] Fail | |
| **No Fear Tactics:** Does the flow avoid manipulative claims (e.g., threatening immediate total data deletion within 24 hours)? | [ ] Pass<br>[ ] Fail | |

## 2. Diagnostic Survey & Intent Mapping

| Audit Criteria | Status | Issues Identified / Action Items |
| :--- | :---: | :--- |
| **Single Diagnostic Question:** Is the survey limited to 1 primary question with 4-5 clear, mutually exclusive reason choices? | [ ] Pass<br>[ ] Fail | |

---

## 3. Reason-Matched Deflection Offer Strategy Matrix

Use this matrix to map user survey responses directly to single, high-converting deflection offers:

| Primary Exit Reason | Matched Deflection Offer | Secondary / Fallback Option | Primary Objective |
| :--- | :--- | :--- | :--- |
| **"Not using it enough right now" / "Temporary break"** | **1-Click Account Pause**<br>(Pause billing for 30, 60, or 90 days; maintain setup and data) | **Archive / View-Only Plan**<br>($0/mo or nominal fee to keep historical data accessible) | Retain subscriber relationship without price erosion. |
| **"Too expensive" / "Need to cut budget"** | **Starter / Lite Tier Downgrade**<br>(Lower monthly cost matching core active features) | **Temporary Billing Relief**<br>(30-50% off for 2-3 months) | Retain account on lower MRR rather than losing 100%. |
| **"Missing specific features"** | **1-on-1 Specialist Session** or **Roadmap Preview**<br>(Direct calendar booking with support/product) | **Beta Access Unlock**<br>(Grant early access to upcoming feature branch) | Solve setup/adoption bottleneck or prove feature delivery. |
| **"Too hard to use / onboarding friction"** | **Guided Concierge Setup**<br>(Free technical migration or setup consultation) | **Self-Paced Masterclass**<br>(Curated 5-minute video walkthrough) | Resolve initial time-to-value deficit. |
| **"Switching to competitor"** | **Feature/Value Comparison Spotlight**<br>(Highlight unique capabilities not present in competitors) | **Custom Plan Alignment**<br>(Match specific feature/seat requirements) | Reinforce unique value proposition and switching costs. |

## 4. Friction & Confirmation UX Evaluation

| Audit Criteria | Status | Issues Identified / Action Items |
| :--- | :---: | :--- |
| **Maximum 3 Steps:** Is the complete cancellation flow structured in 3 or fewer total screens? | [ ] Pass<br>[ ] Fail | |
| **Clear Renewal & Expiration Summary:** Is the exact end date of access explicitly displayed on the final confirmation screen? | [ ] Pass<br>[ ] Fail | |
| **1-Click Re-activation:** Is an instant "Re-activate Plan" CTA displayed on the billing dashboard during the grace period? | [ ] Pass<br>[ ] Fail | |
| **Email Confirmation Dispatch:** Is an automated, non-aggressive cancellation confirmation email dispatched immediately with access details? | [ ] Pass<br>[ ] Fail | |

---

## 5. Scoring & Maturity Model

- **20-24 Points (Retention Master):** Your cancellation flow is compliant, low-friction, and highly effective at saving temporary churners through targeted offers.
- **14-19 Points (Moderate Risk):** Good foundation, but missing 1-click account pause options or reason-matched offer logic.
- **Below 14 Points (High Churn & Regulatory Risk):** Immediate remediation required. High vulnerability to dark pattern penalties, negative reviews, and excessive MRR loss.
