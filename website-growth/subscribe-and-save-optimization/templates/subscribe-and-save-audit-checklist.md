## Part 1: Diagnostic Scoring Rubric (100-Point Scale)

Evaluate each item on a scale from **0 to 5 points**:
- **0 = Non-existent / Severely Broken**
- **3 = Partially Implemented / Minor Friction**
- **5 = Fully Optimized / Best Practice Standard**

| Diagnostic Item | Max Score | Actual Score | Observations & Notes |
| :--- | :---: | :---: | :--- |
| **1. Dual-Radio Selector Layout:** Are One-Time and Subscribe & Save options presented as clear, distinct radio card containers rather than hidden inside a tiny select dropdown? | 5 | | |
| **2. Dynamic Strikethrough Pricing:** Is the full retail price crossed out (`~~$40~~`) right next to the discounted subscription price (`$34`)? | 5 | | |

| **5. Visual Hierarchy & "Most Popular" Tag:** Is the Subscribe & Save card visually distinguished using a highlight border, accent background, or "Best Value / Most Popular" tag? | 5 | | |
| **6. Dynamic CTA Button Text:** Does the primary purchase button text update dynamically when switching options (e.g., *"Subscribe & Save - $34.00"* vs *"Add to Cart - $40.00"*)? | 5 | | |

### Performance Grade Scale

- 🔴 **0–59 Points (Critical Friction):** Severe conversion leak. Subscription options are hidden, confusing, or trigger high commitment anxiety. Immediate redesign required.
- 🟡 **60–79 Points (Moderate Optimization Opportunity):** Sub-optimal performance. Widget exists but lacks clear dollar savings, cart drawer upgrade paths, or risk-reversal microcopy.
- 🟢 **80–100 Points (High-Converting Subscription Architecture):** Fully optimized. Meets best-practice choice architecture, clear risk reversal, and mobile ergonomics.
