# E-Commerce Sizing & Fit Experience Audit Checklist

This audit template is designed for e-commerce growth practitioners, UX designers, and optimization strategists to evaluate and improve on-page size guides, fit charts, and predictive advisor tools.

Use this checklist on key high-traffic Product Detail Pages (PDPs) to identify sizing friction and opportunities to reduce returns.

---

## 1. Visual Placement & Proximity (Score: `__` / 10)

- [ ] **Proximity to Selector:** Is the "Size Guide" or "Find My Fit" link positioned directly above or next to the size-selection buttons? (Score: `__` / 3)
- [ ] **Contrast & Design:** Is the link visually distinct? Does it feature a clean, recognizable icon (e.g., a ruler or measuring tape 📏) to draw focus without cluttering the buy-box? (Score: `__` / 2)
- [ ] **Persistent Mobile Access:** On mobile viewports, is the size guide link easily tappable (minimum 44x44px touch target) and positioned above the fold? (Score: `__` / 3)
- [ ] **Consistent Styling:** Is the link styled consistently across all product lines (tops, bottoms, footwear) rather than shifting layout? (Score: `__` / 2)

---

## 2. Size Guide Layout & Usability (Score: `__` / 15)

- [ ] **Mobile-Responsive HTML:** Are size charts built using responsive HTML/CSS instead of a static, un-zoomable image or a downloadable PDF file? (Score: `__` / 4)
- [ ] **Hover/Focus Highlighting:** Do table rows or cells highlight when hovered or focused, allowing the user to scan horizontally across complex measurement columns without losing their place? (Score: `__` / 2)
- [ ] **Unit Toggle Tab:** Is there an instant, high-contrast toggle tab allowing users to switch between Imperial units (Inches) and Metric units (Centimeters) with zero page reloads? (Score: `__` / 3)
- [ ] **International Sizing Toggles:** If selling globally, does the chart provide instant toggling between standard regional conventions (e.g., US, UK, EU, JP sizing)? (Score: `__` / 3)
- [ ] **Anatomical Mapping Diagram:** Does the modal contain a simple vector graphic or clean line illustration showing exactly where the body measurements should be taken? (Score: `__` / 3)

---

## 3. Dynamic Fit Data & Social Proof (Score: `__` / 15)

- [ ] **Fit Spectrum Slider:** Is there a visual on-page indicator (e.g., a horizontal slider) showing aggregate buyer feedback on how the item fits ("Runs Small" vs "True to Size" vs "Runs Large")? (Score: `__` / 4)
- [ ] **PDP Model Specifications:** Does the page clearly state the model's physical measurements and the size they are wearing (e.g., *"Model is 5'11\" wearing size L"*)? (Score: `__` / 3)
- [ ] **Contextual Size Prompts:** If a specific style or fabric run deviates from standard sizing (e.g., "100% Cotton, shrinks in wash"), is there an explicit warning recommending that users size up? (Score: `__` / 4)
- [ ] **Review Filter Integration:** Can users filter product reviews specifically by sizing/fit ratings or by reviewer biometrics (e.g., "Show reviews by customers who are 5'10\" and 180 lbs")? (Score: `__` / 4)

---

## 4. Personalized Sizing Logic (Score: `__` / 10)

- [ ] **Predictive Advisor Tool:** Is there an interactive "Find Your Size" fit advisor that recommends sizes based on standard biometric inputs (height, weight, age, preferred fit)? (Score: `__` / 4)
- [ ] **Comparative Brand Matching:** Does the predictive advisor allow users to select sizes they wear in well-known peer brands to calculate a match (e.g., "I wear Medium in Patagonia")? (Score: `__` / 3)
- [ ] **Zero-Gated Access:** Can users access the sizing quiz and get their size recommendation instantly without being forced to sign up, input an email, or log in? (Score: `__` / 3)

---

## 5. Bracketing Mitigation & Cart Experience (Score: `__` / 10)

- [ ] **Duplicate Size Cart Alert:** Does the cart drawer automatically detect when a user adds the exact same item in multiple sizes and gently nudges them to use the sizing advisor instead of bracketing? (Score: `__` / 4)
- [ ] **Exchanges Reassurance Microcopy:** Is there a reassurance line near the Checkout button stating that size exchanges are 100% free and easy (reducing pre-purchase anxiety)? (Score: `__` / 3)
- [ ] **Post-Purchase Feedback Integration:** Do returned products require sizing feedback (e.g., "Returned because it was too narrow"), and is this data dynamically routed to optimize the fit spectrums? (Score: `__` / 3)

### Sizing Grade Heuristics:
- **Grade A (50-60):** Outstanding. Sizing friction is non-existent. Buyers have complete confidence, leading to high conversions and minimal returns.
- **Grade B (40-49):** Strong. Minor improvements needed around interactive features or mobile responsive layouts.
- **Grade C (30-39):** Moderate Friction. Sizing information is present but hard to read, static, or lacks dynamic reviews data. Return rates are likely elevated.
- **Grade F (<30):** High Risk. Static blur images, hidden links, or zero guidance are driving high cart abandonment and massive bracketing returns. Immediate overhaul required.
